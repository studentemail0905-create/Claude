# Swipe — Templates, Scripts, Libraries, Output Format

Fill-in templates, ready-to-use scripts, swipe libraries, and the final output artifact format. Pull what you need for the current phase.

## Fill-in templates

### Avatar Definition
> My customer is a **[role/identity]** who **[situation/qualifier]**, wants **[dream outcome]**, and currently struggles with **[core pain]**. They are NOT **[who to exclude]**.

*(Gym Launch example: microgym owner, ~100 members, signed lease, ≥1 employee, wants weight-loss clients — NOT personal trainers, NOT online coaches.)*

### Positioning Statement
> "I solve **[this type of problem]** for **[this specific person]** in a unique, counter-intuitive way that reverses **[their deepest fear]**."

### Dream Outcome
> "**[Big, specific result]** in **[short timeframe]**" — and the vacation behind it: *they don't want [the product], they want [the life it creates]*.

### Problem grid (one row per customer action)
| Action they must take | Dream-Outcome problem | Likelihood problem | Effort problem | Time problem |
|---|---|---|---|---|
| e.g. Buy healthy food | not worth the cost | won't work for my body | too confusing | takes too long |

### Problem → Solution converter
| Problem | "How to" + reversed | Driver covered |
|---|---|---|
| Healthy food is expensive | How to buy healthy food for less than your current grocery bill | Effort/$ |

### Stack Builder (the core artifact)
| # | Problem it solves | Bundle name (sexier) | Delivery vehicle(s) | $ Value |
|---|---|---|---|---|
| 1 | | | | $ |
| … | | | | $ |
| | | **Total Value** | | **$X** |
| | | **Your Price** | | **$Y** (Y ≪ X) |

### Bonus Builder (run the 11 Bullets on each)
> **[Benefit-rich name]** ($ value) — *Relates to:* [their issue]. *What it is:* […]. *How I made it:* […]. *How it improves life:* [faster/easier/less effort]. *Proof:* […]. *Picture this:* [after-image]. *Objection it kills:* […].

### Guarantee Builder
> "If you **don't [X result]** within **[Y time]**, we will **[Z remedy]**." — Type: [Unconditional / Conditional / Anti / Implied]. Name: "**[Creative Name] Guarantee**." Conditions (to filter freeloaders): [required client actions].

### MAGIC Name generator (assemble 3–5 components)
> [Magnetic reason-why] + [Avatar] + [Goal] + [Interval] + [Container word]
> e.g. "Free" + "Busy Mom" + "Slim-Down" + "6-Week" + "Challenge" → **"The Busy Mom 6-Week Slim-Down Challenge"**

## Scripts (ready to adapt)

**Pricing reframe (conviction close):**
> "If I made you **$[big number]** this year, would you happily pay me **$[your price]**?"

**Best-case / worst-case close:**
> "Best case, you get [dream outcome] and we keep supporting you. Worst case, you tell me I suck, I write you a check, and you got the whole thing free anyway. The only thing guaranteed *not* to help you is walking out today."

**Cohort urgency (base):**
> "If you sign up today, I can get you into our next group that kicks off **[day]** — otherwise you'll have to wait until the next kickoff."

**Cohort urgency (juiced):**
> "A client who signed up a few weeks ago just dropped, so I have one opening for the cohort kicking off **[day]**. If you're going to do this sooner or later, might as well start reaping the rewards now rather than paying the same and waiting."

**Price-increase announcement (position of strength):**
> "Heads up — the price is going up on **[date]**. Get in now at the current rate."

**Scarcity bonus (exclusivity):**
> "Only people who sign up for **[offer]** get **[Bonus 1, 2, 3]** — never sold separately, never available anywhere else."

**Urgency bonus (time-bound):**
> "Buy today and I'll add **[bonus]** (normally $[value]) free — my way of rewarding action-takers."

## Calculator quick-reference (compute live with the user's numbers)

- **LTV/LTGP** = Monthly Rev × Gross Margin % × Lifespan (months)
- **Revenue Cap** = New clients/mo × LTV
- **Value-to-Price discrepancy** = Total stacked value ÷ Price (aim ≫ 1)
- **Guarantee ROI** = net sales *with* guarantee ÷ net sales *without* (e.g. 117/95 = 1.23×)
- **Before/After money math** = response-rate multiple × close-rate multiple × price multiple
- **First-$100K runway** = personal savings ÷ annual living expenses
